# A3 - Gnani Voice Adapter

**Branch:** `agent/A3-gnani-voice`  
**Owner:** Advait side  
**Read first:** `docs/PRD.md`, `docs/TRD.md`, `docs/RUNBOOK.md`, `docs/AGENT_RULES.md`.

## Objective

Provide a small voice adapter for Gnani Prisma STT and Timbre TTS, plus a clearly labeled mock/text fallback if credentials/API access are unavailable.

## Exclusive write paths

- `backend/app/voice/**`

Do not edit API contracts/routes, frontend, manifests, docs, or another agent's code. Request A1 to adjust the contract, Advait for environment/docs, and A4 for UI status wiring.

## Interfaces to coordinate

Return normalized transcript/intents or typed service errors; accept plain text for fallback; expose adapter status. Use secrets only from environment/config. Never print or commit API keys.

## Done when

- Real adapter has a successful smoke test, or the fallback is explicitly labeled and works.
- STT/TTS failures return understandable typed errors without blocking the core text flow.
- Owner report distinguishes real integration from mock behavior.
