# A1 - Backend Foundation and API

**Branch:** `agent/A1-backend-api`  
**Owner:** Advait side  
**Read first:** `docs/PRD.md`, `docs/TRD.md`, `docs/RUNBOOK.md`, `docs/AGENT_RULES.md`.

## Objective

Own the FastAPI application foundation, routes, Pydantic shared contracts, and application orchestration seams. Publish contract changes before consumers implement against them.

## Exclusive write paths

- `backend/app/main.py`
- `backend/app/api/**`
- `backend/app/core/**`
- `backend/app/schemas/**`
- `backend/pyproject.toml`

Do not edit memory, voice, browser, learning, execution, frontend, docs, README, or root integration files. Ask Advait for shared root changes and ask the appropriate module owner for service changes.

## Interfaces to coordinate

Own `contracts.py`; coordinate request/response fields and status events with A2/A3/A4/U1-U4. Use dependency injection or protocols so owned routes can call agent modules without editing their files.

## Done when

- App starts and health route responds.
- Agreed schemas validate requests and responses.
- Routes expose teach start/stop, workflow list/detail/approval, execute, pause/stop, and status according to frozen contract.
- Owner report lists actual checks run and interfaces still stubbed.
