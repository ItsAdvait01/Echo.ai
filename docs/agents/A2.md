# A2 - Workflow Memory

**Branch:** `agent/A2-workflow-memory`  
**Owner:** Advait side  
**Read first:** `docs/PRD.md`, `docs/TRD.md`, `docs/RUNBOOK.md`, `docs/AGENT_RULES.md`.

## Objective

Implement storage and retrieval for approved workflows, execution runs, and verified checkpoints. Enforce approval status at the persistence boundary.

## Exclusive write paths

- `backend/app/memory/**`

Do not edit A1 schemas/routes, other agent modules, dependency manifests, README, or docs. If schema fields or a package dependency need changing, request it from A1/Advait.

## Interfaces to coordinate

Consume `backend/app/schemas/contracts.py` as published by A1. Expose a small repository interface for create/list/get/approve/update-progress; coordinate method names with A1 before wiring.

## Done when

- Approved workflow can be persisted and retrieved.
- Rejected/unapproved draft is not returned as executable memory.
- Checkpoint updates are stored only when caller supplies a verified result.
- Owner report states whether SQLite or an explicit temporary in-memory adapter was used.
