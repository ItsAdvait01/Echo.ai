# U1 - Browser Observer

**Branch:** `agent/U1-browser-observer`  
**Owner:** Kshitij side  
**Read first:** `docs/PRD.md`, `docs/TRD.md`, `docs/RUNBOOK.md`, `docs/AGENT_RULES.md`.

## Objective

Implement an explicitly started/stopped Playwright session and emit normalized, task-scoped browser events. Do not watch arbitrary user browsing.

## Exclusive write paths

- `backend/app/browser/**`

Do not edit A1 routes/contracts, U2 learner, U3/U4 execution, storage, frontend, or docs. Ask A1 to add/change event contract fields.

## Interfaces to coordinate

Consume A1 `BrowserEvent` schema and session lifecycle. Provide observer start/stop and event collection methods; share the method signature before integration.

## Done when

- Observation requires explicit session start and immediately honors stop.
- Relevant navigation/action/page signals are captured for chosen demo site.
- Sensitive fields and unrelated page data are filtered.
- Owner report distinguishes live observation from fixtures.
