## Objective

Given an approved workflow and current browser state, select and perform the next supported action using validated semantic targets. Never blindly replay coordinates.

## Exclusive write paths

- `backend/app/execution/planner.py`
- `backend/app/execution/executor.py`

Do not edit U4 verifier/recovery, A1 contracts/routes, browser observer, storage, UI, or docs. Ask U4 to change verification behavior and A1 to change contract fields.

## Interfaces to coordinate

Consume approved Workflow/WorkflowStep and BrowserSession protocols; return an execution result for U4 to verify. Do not update persistent checkpoint directly; A2/A1 own persistence orchestration.

## Done when

- Only allowlisted actions can execute.
- Target existence/uniqueness is checked before interaction.
- Missing or ambiguous target returns a safe structured result and stops.
- No action is treated as completed before U4 verification.
