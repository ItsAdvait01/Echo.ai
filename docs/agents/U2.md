# U2 - Workflow Interpreter and Learner

**Branch:** `agent/U2-workflow-learner`  
**Owner:** Kshitij side  
**Read first:** `docs/PRD.md`, `docs/TRD.md`, `docs/RUNBOOK.md`, `docs/AGENT_RULES.md`.

## Objective

Convert normalized observed events into an understandable structured workflow draft. Keep observed facts separate from inferred intent and expose uncertainty for review.

## Exclusive write paths

- `backend/app/learning/**`

Do not edit U1 observer, A1 contracts/routes, A2 memory, UI, or docs. Ask A1 to change shared schema; ask U1 to add event information.

## Interfaces to coordinate

Consume the published `BrowserEvent` contract and return the published `WorkflowDraft` contract. Do not save or approve directly; approval/persistence belong to A1/A2.

## Done when

- A short event trace produces a draft with name, ordered action intent, targets, expected result, and uncertainty notes.
- Observations and interpretations remain distinguishable.
- No draft is silently marked approved or persisted as runnable.
