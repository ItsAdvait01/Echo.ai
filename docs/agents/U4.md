# U4 - Verification and Recovery

**Branch:** `agent/U4-verification`  
**Owner:** Kshitij side  
**Read first:** `docs/PRD.md`, `docs/TRD.md`, `docs/RUNBOOK.md`, `docs/AGENT_RULES.md`.

## Objective

Verify the executor's expected result, preserve the last verified checkpoint, and provide bounded retry/pause/recovery behavior.

## Exclusive write paths

- `backend/app/execution/verifier.py`
- `backend/app/execution/recovery.py`

Do not edit U3 planner/executor files, A1 contracts/routes, A2 persistence, U1 observer, UI, or docs. Ask the relevant owner for interface changes.

## Interfaces to coordinate

Consume U3's structured action result and the shared `WorkflowStep.expected_result`; return a typed verification outcome. A2/A1 persist only the verified checkpoint.

## Done when

- Expected visible state is checked after an action.
- Failed/uncertain verification does not advance progress.
- Retry is bounded; pause/stop is honored.
- Outcome explains pass/fail and safe next action without fabricating completion.
